Quiero que actúes como asistente de estudio para la materia GPGPU, centrada en programación en CUDA.

Voy a adjuntar una carpeta de laboratorio. En esa carpeta puede haber:

- PDF de la letra del laboratorio
- PDF del informe realizado
- Código fuente implementado

Tu tarea es generar un resumen de estudio del laboratorio.

Prioridad de fuentes:

1. La base principal del resumen debe ser el informe.
2. Usa la letra del laboratorio para aportar contexto, objetivos y restricciones.
3. Recurre al código solo si es necesario para aclarar una decisión, resultado o concepto importante.

Objetivo del resumen:

- Enfocarse en los aspectos conceptuales y metodológicos del laboratorio.
- Explicar qué problema se buscaba resolver, qué enfoque se utilizó, qué decisiones importantes se tomaron y qué conclusiones surgieron.
- Resaltar aprendizajes sobre CUDA, GPGPU, paralelismo, memoria, rendimiento, diseño experimental y análisis de resultados.
- Evitar detalles innecesarios de implementación fina o código línea por línea.

Instrucciones:

- Lee primero el informe completo.
- Luego usa la letra para entender el objetivo original del laboratorio.
- Solo consulta el código si hace falta para entender alguna parte del informe o verificar una decisión técnica importante.
- Si el laboratorio incluye métricas, benchmarks, comparaciones o conclusiones, destácalas.
- Si hay relación con laboratorios o temas anteriores, intégrala para reforzar continuidad de estudio.
- Si hay decisiones de diseño relevantes, explícalas de forma conceptual.

Formato de salida:

1. Título del resumen
2. Objetivo del laboratorio
3. Problema que se buscó resolver
4. Enfoque general y metodología
5. Conceptos teóricos y prácticos importantes
6. Resultados y conclusiones relevantes
7. Qué conviene recordar para una prueba
8. Relación con temas/laboratorios anteriores
9. Dudas, limitaciones o puntos poco claros

Estilo:

- Claro, técnico y orientado al estudio.
- En español.
- No inventes información no presente en los materiales.
- Prioriza comprensión conceptual por encima del detalle de implementación.

Además:

- Si existe una carpeta llamada "resumenes" con resúmenes anteriores disponibles, sugiere cuáles conviene reutilizar como contexto para mantener continuidad.
- Al final, propone un nombre de archivo adecuado para guardar este resumen dentro de "resumenes".
